# Mi Step 1.0.3

相较 1.0.2 正式版：

**新增功能**

- 新增澎湃 OS 2 支持。
- 新增平板适配，支持横竖屏布局、独立竖屏小窗和副任务自动补位；竖屏小窗支持双指滑回主区域。
- 新增模块设置，可从「系统设置 → Mi Step」进入，支持浅色、深色主题。
- 支持自定义控制中心和标题栏按钮的显示。
- 主副交换支持「原地放大」「固定主区域」两种模式。
- 新增底部左右横滑唤出手势，关闭系统小白条后可启用。
- 新增「锁屏时保留 MiStep」，解锁后恢复原工作区和任务。
- 新增运行日志与问题录制，支持记录锁屏问题并导出诊断包，方便反馈。
- 新增「关于 MiStep」，提供项目仓库、作者主页及可关闭的自愿捐赠入口。

**优化与修复**

- 优化小屏幕控制中心布局，修复按钮、文字显示不全的问题。
- 修复部分澎湃 OS 3 设备在桌面上滑进入后台时意外退出 MiStep 的问题。
- 修复屏幕指纹动画及应用指纹验证界面缩放、位置异常的问题。

升级前退出 MiStep，覆盖安装后正常重启生效。推荐作用域为「系统框架」「系统界面」「设置」；设置作用域用于模块设置入口。
