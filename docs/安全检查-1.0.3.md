# 1.0.3 发布检查

发布内容限定为产品源码白名单及 APK、源码 ZIP、构建信息和 SHA256 清单四个附件。研究材料、ROM、反编译原件、手机诊断包、设备连接信息、签名密钥及构建缓存不公开。

检查待发布源码、嵌套编译依赖及 APK 的凭据、本机路径、私有地址、真实设备标识、旧包名和个人邮箱残留；核对 APK 内许可证。公开提交使用 GitHub noreply 身份，发布后核对 main、标签、发行正文、源码树、附件大小和摘要，并验证旧版本标签与附件保持原样。

源码遵循 `LicenseRef-MiStep-NC-SA-1.0`，属于非商用、相同方式共享的 Source Available，不宣称 OSI 开源或 GPL。构建与实机证据边界见[验证说明](验证说明-1.0.3.md)。
