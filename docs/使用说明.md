# Mi Step 使用说明

## 安装和启用

1. 确认手机已有可用的 Root 和 LSPosed，系统属于本项目当前适配范围。
2. 下载并核对 `MiStep-1.0.0.apk`，安装后在 LSPosed 中启用 **Mi Step**。
3. 按模块推荐选择作用域：系统框架 `android`、系统界面 `com.android.systemui`、设置 `com.android.settings`；使用小米输入法时再选择 `com.xiaomi.type`。
4. 正常重启手机，让系统进程重新加载模块。

模块没有普通启动 Activity，安装后没有独立的桌面主界面。不要为歌词功能额外勾选汽水音乐、酷狗或其它播放器作用域；当前版本通过已有媒体信息和可调用接口取词。

## 打开、交换、退出

- 在竖屏界面，从**左上角向右**或**右上角向左**滑动。主区域在手势的另一侧，副任务区出现在起始侧。
- 点击空副任务格中的 **＋**，选择应用。点击已有副任务可与主区域交换。
- 副任务可向外拖动；其内部内容以主副交换后的主区域操作为主。
- 点击顶部退出按钮关闭工作区，恢复普通系统界面。主副交接过程中会暂时保护输入，交接和最终画面提交完成后恢复操作。

系统快捷操作、音乐卡片和歌词均依赖手机上相应服务。歌词缺失、纯音乐或服务未匹配到曲目时，不保证显示歌词。微信等应用的具体快捷功能可能需要先在桌面添加对应快捷方式。

## 升级和恢复

1. 升级前先退出工作区，保留当前可用 APK。
2. 使用同一签名的版本覆盖安装，正常重启。1.0.0 的版本码为 `1000000`，高于前期开发版。
3. 若系统更新后出现界面或触摸异常，先退出工作区；仍异常时，在 LSPosed 中停用模块并正常重启。无法进入系统时，使用自己所用 Root / LSPosed 方案的恢复方法停用模块。

发行包沿用本项目开发期签名身份，以保留覆盖升级能力。该身份不是应用商店发行证书；自行构建并换用其它密钥签名后，不能直接覆盖安装现有包。

## 已知边界

当前以 Android 17 / 澎湃 OS 4 的已研究接口为基准。设备型号相同但 ROM 不同，也需要单独核验。1.0.0 已包含一步内部横屏输入、悬浮键盘限位、主副交换旋转和状态栏动画越界修复；其开发基线的具体实测范围见 [发行说明](发行说明-1.0.0.md)。通知拖窗、硬件副屏以及所有第三方应用组合并未获得统一验收结论。本次重新打包的发行 APK 未额外安装到手机。
