# Mi Step 使用说明

## 安装和启用

模块包名为 `com.jiusis.mistep`，以后版本沿用此标识。

1. 确认手机已有可用的 Root 和 LSPosed，系统属于本项目当前适配范围。
2. 下载并核对 `MiStep-1.0.3.apk`，安装后在 LSPosed 中启用 **Mi Step**。
3. 推荐选择系统框架 `android`、系统界面 `com.android.systemui`，以及仅用于模块入口的设置 `com.android.settings`。使用小米输入法且需要阻止横屏自动变成悬浮键盘时，可另选 `com.xiaomi.type`；其余普通应用无需勾选。旧的标准抖音TOP图片专用补丁已撤回，不再需要其作用域。升级不会自动清除LSPosed保存的旧勾选，可自行取消多余项。
4. 正常重启手机，让系统进程重新加载模块。

安装后可从 **系统设置 → Mi Step** 打开模块设置页，入口位于“我的设备”下方，无独立桌面图标。界面采用统一的澎湃 OS 4 风格并跟随系统浅色/深色主题。支持以下设置和诊断功能：

- **按钮显示**：控制中心整体、Wi-Fi、移动数据、蓝牙、VPN、机型信息、付款码、扫一扫、乘车码、音量和亮度可分别控制显示；标题栏的退出、系统设置、剪贴板、前后快捷应用、手电筒、截图、录屏也可分别控制。默认全部显示，修改后同步到工作台。
- **主副交换逻辑**：默认“原地放大”，副任务在原侧放大，主区域随之换边；“固定主区域”保持主区域在当前一侧，只交换应用。切换从下一次交换生效，不立即移动当前任务。两种模式都使用真实应用任务与动画。
- **唤出手势**：默认状态栏向内滑；关闭系统小白条后，可选择从物理屏幕底部任意位置向左或向右横滑。
- **锁屏时保留 MiStep**：开启后保留工作区及任务，原生解锁后恢复；默认关闭。
- **运行日志**：支持刷新、填写问题描述和导出 ZIP 诊断包。可先点击“开始录制问题”，在最长 60 秒内复现后返回结束，支持跨锁屏记录窗口变化。首次读取系统侧记录需授予 Mi Step Root 权限。包内包含版本、设置、近期模块及系统日志、任务、窗口和输入变换等信息；缺失或失败会如实标记，不自动上传。反馈前请检查包内个人信息。
- **关于 MiStep**：查看项目与作者主页；自愿捐赠入口可长按临时或永久关闭。

选择保存在本机，退出或重启后保留。工作台继续通过下述手势进入。不要为歌词功能额外勾选汽水音乐、酷狗或其它播放器作用域；当前版本通过已有媒体信息和可调用接口取词。

## 打开、交换、退出

- 当前版本在普通竖屏状态栏可见时允许角部入口。沉浸全屏需先拉出原生状态栏、保持通知与快捷面板未展开，再另起角部手势；未拉出不允许，横屏规则相同且实际游戏仍待验收。从**左上角向右**或**右上角向左**滑动。主区域在手势的另一侧，副任务区出现在起始侧。
- 先在主区域打开应用，再点击空副任务格中的 **＋**，将当前主应用收进该格。主区域是桌面时，先打开要收纳的应用；「＋」不打开应用选择器。
- 点击已有副任务可与主区域交换。完整点击、滚动和输入在主区域进行；副任务区用于点按交换和向外滑出。
- 将副任务向所在屏幕外侧滑出，可腾出该格，任务交还系统并留在后台，不主动结束应用。
- 点击顶部退出按钮关闭工作区，恢复普通系统界面。主副交接过程中会暂时保护输入，交接和最终画面提交完成后恢复操作。

快捷应用栏长按任意应用图标可打开自定义应用选择框，支持搜索、多选；点击「完成」后按选择顺序固定在最前，其余应用继续按常用顺序排列。再次长按可取消勾选，点击「取消」不保存改动。普通点击打开应用、横向滑动浏览；原长按拖动选中后松手启动手势已替换。配置按系统用户保存，退出工作区或正常重启后保留。

系统快捷操作、音乐卡片和歌词均依赖手机上相应服务。歌词缺失、纯音乐或服务未匹配到曲目时，不保证显示歌词。微信等应用的具体快捷功能可能需要先在桌面添加对应快捷方式。

## 升级和恢复

顶部区域双指上下滑动可切换控制面与任务面；控制中心共两页。先在主屏打开应用，再点顶部空位「＋」收纳；窗口内可单指操作、换页和返回，双指横向滑出可将应用留在后台。应用方向变化不会自动占用顶部。收纳、翻回和主副交换使用真实应用画面动画；返回控制中心时，已有主屏应用保持原样。平板横屏有独立竖屏任务区，可双指向主区域滑回原任务，再次收纳时恢复被覆盖的主任务。完整改动见[1.0.3 更新日志](发行说明-1.0.3.md)。

1. 升级前先退出工作区，保留当前可用 APK。旧包名版本需先在 LSPosed 中停用，再安装当前包、启用新模块并重新选择作用域；不要同时启用两个模块，正常重启且确认可用后可卸载旧模块。
2. 只有包名和签名均相同的版本才能覆盖升级。1.0.0 的版本码为 `1000000`；改包名后的 1.0.0 需独立安装，后续同包名版本按版本码递增升级。
3. 若系统更新后出现界面或触摸异常，先退出工作区；仍异常时，在 LSPosed 中停用模块并正常重启。无法进入系统时，使用自己所用 Root / LSPosed 方案的恢复方法停用模块。

发行包沿用本项目开发期签名身份；改包名不会迁移旧模块的启用状态、作用域或应用数据。该身份不是应用商店发行证书；自行构建并换用其它密钥签名后，也不能直接覆盖安装同包名现有包。

## 已知边界

1.0.3 最低安装版本为 Android 14 / API 34，适配澎湃 OS 2 / 3 / 4。最低安装版本不代表所有 ROM 均通过验证；本轮实机覆盖 OS 2 / Android 15 手机和 OS 4 / Android 17 手机、平板，OS 3 的历史结果与本轮范围分别见[1.0.3 验证说明](验证说明-1.0.3.md)。Android 14、OS 2 / OS 3 平板及所有第三方应用组合仍需对应设备核验。

平板按呼出时的横竖方向建立工作区，调整控制中心、文字、图标和任务区布局。退出后可旋转屏幕再次呼出；工作区内保留当前会话方向。部分机型主区域不缩放、部分图文评论排版、通知拖窗和硬件副屏仍无完整修复或统一验收结论。
