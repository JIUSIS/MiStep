本次按作者已选择的“非商用、分发衍生版本公开完整对应源码、沿用同一许可”要求，核查现有 **Mi Step 非商用共享源码许可 1.0**。许可正文保持不变；本记录说明文本覆盖范围与实际分发检查，不作特定司法地区效力结论。

## 本次补齐

- 构建脚本把中文许可全文、第三方说明及现有全部上游许可/NOTICE 原文放入 APK 的 `assets/mistep/licenses/`，并标明项目源码地址。源码 ZIP 和对应标签也包含这些材料。
- 包检查脚本要求上述声明存在；发布检查逐字核对 APK 内文本与源文件一致，避免“仓库有声明但安装包没有”的分发缺口。
- 许可说明纠正源码保留期限：随每份副本提供源码归档可替代停止分发后的保留义务，分发期间仍须提供公开源码地址。
- 中文与英文 README 均标为 Source Available，并清楚说明英文 README 是阅读辅助，中文许可正文为准。
- 许可说明与发行说明同步本次重建、包名及校验值变化，删除不再适用的“附件字节不变”描述。

## 结论与边界

现有条款覆盖本次明确的产品授权要求，未擅自换成允许商用的 GPL，也未新增或收紧许可 1.0 条款。非商用限制意味着它不满足 OSI 开源定义；`LicenseRef-MiStep-NC-SA-1.0` 是自定义标识，不表示 SPDX 或 OSI 批准。

本次未引入新的第三方实现。自愿捐赠、企业内部使用等具体行为仍应依许可正文的商业化定义判断；若作者将来要为这些情况另设明确授权，应另行作出决定，避免只在 README 中改变授权。
