# 1.0.2 发布检查

发布范围只包含产品源码白名单及四个附件：APK、源码 ZIP、构建信息和 SHA256 清单。研究材料、手机日志、截图、设备连接信息、签名密钥及构建缓存不在公开范围。

发布前检查源码、嵌套依赖 JAR 和 APK 中的凭据、私有地址、本机路径、设备标识与旧包名，并核对 APK 内许可证。源码以非商用、相同方式共享条款公开，标识为 `LicenseRef-MiStep-NC-SA-1.0`，属于 Source Available；不宣称为 OSI 开源或 GPL。

公开产品提交使用 GitHub noreply 身份。发布后核对主分支与版本标签、发行正文、四个附件的服务端大小和 SHA256，并复核已有 1.0.0、1.0.1 的标签和附件保持不变。完整技术验证范围见[验证说明](验证说明-1.0.2.md)。
