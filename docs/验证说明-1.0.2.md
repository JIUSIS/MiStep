# 1.0.2 验证说明

## 正式包

版本为 `1.0.2 / 1000072`，延续原签名，避免已安装测试版无法直接升级。由完整 Java 和 ARM64 原生源码重新构建；签名、ZIP 完整性、16 KB 对齐、许可证及项目全部离线测试均列为发布检查。附件摘要见同发行页的 `SHA256SUMS.txt`。

运行代码以已验内部 71 为基线，只更新正式版元数据；测试脚本另移除机器专用 JDK 路径。正式 72 未在本轮重新安装到手机，不把构建通过当作新的实机验收。

## 已有实机证据

- Redmi Note 11T Pro，Android 16 / HyperOS OS3.0.301：主区缩放、真实副任务收纳、主副交换、同任务返回及退出；主区触点及横屏小窗和主区输入法。
- 同机横屏小窗：真实应用层收纳及翻回、B 站和抖音上翻、横向滑出后任务留在后台；状态栏深浅色与侧边工具箱动画另有用户反馈确认。
- 小米 17 Pro Max，Android 17 / HyperOS 4：副窗口直接启动及一次物理点击交换已验证；不能将重启后未重现的旧拒绝现象称为全部根因修复。顶部矩形与动画另按用户反馈收口。
- 11T Pro 内部 71：系统音乐《你那么爱她》、酷狗概念版《Take Me Hand（温柔版）》均获取并实际显示多行歌词；系统音乐歌词随播放推进。椒盐用无内嵌歌词的静音元数据测试文件验证联网取词，测试文件及媒体记录已清理，不代表用户整个本地曲库。

## 范围与限制

- 公开歌词源可能缺曲、存在少量文字或时间差；不能保证所有歌曲均可获取或与原播放器逐字逐秒一致。不向播放器进程注入。
- B 站部分版本的横屏视频偏移通过播放器版本对照确认；本版不把更新 B 站后的改善算作模块修复，也没有新增其作用域。
- 其他 ROM、Android 15、所有应用组合、横屏游戏、硬件副屏及通知拖窗没有统一验收结论。个别机型全局缩放和第三方手势模块组合仍需单独定位。
- 动画保留真实应用 Surface / 任务层，不使用截图或任务快照代替应用窗口。

推荐作用域仍为系统框架和系统界面；旧版本说明保留各自当时的验证范围。
