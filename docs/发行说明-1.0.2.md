# Mi Step 1.0.2

相较 1.0.1：

- 新增澎湃 OS 3（Android 16）支持。
- 横屏小窗支持双指横向滑出，应用保留在后台；控制中心精简为两页，保留双指上下翻面。
- 优化横屏小窗收纳、翻回动画，修复黑框、层级错乱和顶部闪出小矩形的问题。
- 修复横屏小窗存在时，主屏输入法、边缘返回及状态栏显示、取色异常。
- 修复部分设备副窗口无法点击、交换，侧边工具箱可跟随交换动画。
- 优化交换时控制中心和灵动岛显示，以及全屏应用的角部进入手势。
- 修复系统音乐、酷狗概念版部分歌曲无歌词，完善椒盐等本地播放器联网获取歌词。

退出一步后覆盖安装，重启手机生效。推荐作用域仍为「系统框架」「系统界面」。
