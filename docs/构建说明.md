# 从源码构建 Mi Step

当前构建入口为 Windows PowerShell 脚本。构建每次编译完整 Java 和 C++ 源码，不依赖开发期间的 class 缓存、反编译 ROM 或设备日志。

## 环境

| 工具 | 本版本使用 |
| --- | --- |
| PowerShell | 7 |
| JDK | 支持 `javac --release 17` 的 JDK |
| Android SDK Platform | `android-37.0` |
| Android SDK Build Tools | `37.0.0` |
| Android NDK | `28.2.13676358` |
| Python | 3，运行离线测试；仅使用标准库 |
| Xposed API | 82，`libs/xposed-api-82.jar`，仅编译期使用 |

通过官方 Android SDK Manager 准备上述 SDK 和 NDK。设置 `JAVA_HOME` 与 `ANDROID_HOME`；也可以通过脚本参数 `-JavaHome` 和 `-SdkPath` 指定路径。以上为本版使用的固定环境，不表示要求安装最新版本。

## 不带签名的完整构建

```powershell
./build.ps1 -Unsigned
./test.ps1 -Python python
```

无签名 APK 输出到 `dist/MiStep-1.0.0-unsigned.apk`，不能直接作为正常安装包使用。脚本同时生成 `build-info.json` 和 `SHA256SUMS.txt`。

Java 和原生输入库都从源码编译。原生 ARM64 库采用 16 KB 页对齐，打包后执行 APK 对齐和模块入口检查。D8 对 API 37 的版本支持提示会保留在本机构建日志中；本次构建没有将提示当作功能验收。

## 签名构建

签名密钥放在仓库之外，通过环境变量提供以下配置，再执行 `./build.ps1`：

| 环境变量 | 含义 |
| --- | --- |
| `MISTEP_KEYSTORE` | 本机 keystore 路径 |
| `MISTEP_KEY_ALIAS` | 密钥别名 |
| `MISTEP_STORE_PASSWORD` | keystore 密码 |
| `MISTEP_KEY_PASSWORD` | 私钥密码 |

密码通过 `apksigner` 的环境变量参数读取。仓库没有内置发行密钥或密码。不要把真实配置写进文档、脚本、命令记录或 Git 提交。发行输出为 `dist/MiStep-1.0.0.apk`。

脚本遇到已有签名发行包会停止，避免覆盖已经交付的文件。需要重做发行时，使用新的干净检出目录，并保留原发行物和校验信息。

## 测试范围

`test.ps1` 编译独立 Java 策略测试，执行提取自生产源码的方法回放，再运行模拟 WMS 的任务旋转、层序和最终事务检查。生成的测试源码、模拟类和输出都在 `build/` 中，既不进入 APK，也不提交源码仓库。

原生 ARM64 自测程序随构建生成在 `build/native/native-raw-selftest`。本轮只交叉编译，没有在手机上运行，不计入已执行测试。

离线测试可核查策略、调用次序和模拟系统状态；真实画面、触摸命中、ROM 兼容和异常恢复仍须另行实机验证。

官方参考：[Android SDK Manager](https://developer.android.com/tools/sdkmanager)、[apksigner](https://developer.android.com/tools/apksigner)、[16 KB 页大小](https://developer.android.com/guide/practices/page-sizes)。
