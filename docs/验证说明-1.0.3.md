# 1.0.3 验证说明

## 发行身份与构建

正式版本 `1.0.3 / 1000199`，包名 `com.jiusis.mistep`，延续原签名。完整编译 Java 与 ARM64 原生源码，不使用开发 class 缓存。Manifest、资源链接及 D8 最低 API 为 34，target API 为 37；最低安装版本不等于所有系统均已验收。

发行检查包含全部既有离线测试、APK 签名与 16 KB 对齐、模块入口及原生库打包、源码与 APK 的敏感信息和许可证检查。附件字节摘要以同发行页 `SHA256SUMS.txt` 为准。

运行源码以最终测试候选 `1000198 / wallpaper-test29` 为基线，只调整正式版身份及发行文档。正式发行包本轮不额外装机；既有测试结果与新构建结果分别记录。

## 实机证据范围

- **澎湃 OS 2 / Android 15 手机**：Redmi Note 11T Pro 已验证核心任务收纳、双向主副交换、主区域物理触摸、正常退出、原生控制与音乐、部分 TOP 点击及翻回路径。后续候选已验证一次锁屏保留及恢复。输入法位置、三方应用和所有转场组合未统一验收。
- **澎湃 OS 3 / Android 16 手机**：1.0.2 的历史实机结果保留；本轮增加通用后台手势与兼容处理，但 OS 2 的结果不能代替本次 OS 3 全量复验。
- **澎湃 OS 4 / Android 17 手机**：Xiaomi 17 Pro Max 已验证真实 TOP 点击、指纹动画和验证面板物理原位；最终 test29 一次锁解保留设置、相册副任务，实际酷安主任务恢复到原主区域，锁屏保持原生全屏。未测试实际手指认证，也未在该次轨迹验证 Home 前台锁解。
- **澎湃 OS 4 / Android 17 平板**：Pad 6S Pro 已分别验证横屏多格、独立竖窗、实际补位及交换、双指回主区域与再次收纳、部分输入法与返回、真实入场与锁解恢复。test29 当前实图已消除第四空格矩形色块与硬接缝；保留旧 Host 后格数变化的动态分支仅有离线回归，不能称转屏路径全部实测。

## 已知边界

Android 14、OS 2 / OS 3 平板没有本轮对应硬件验收；不同 ROM 和应用组合需要单独验证。部分机型所有主区域应用不缩放、部分图文评论排版、通知拖窗、硬件副屏及应用内多指操作仍无统一修复或验收结论。

锁屏保留、输入法和转场的单次有界结果不代表所有应用、认证方式或长时间使用均无问题。离线回归、安装、加载标记、画面、物理触摸与恢复分别取证，互不替代。
