# 1.0.4 验证说明

正式版本 `1.0.4 / 1000257`，替换此前发布的 `1000248`，包名 `com.jiusis.mistep`，签名不变。完整编译 Java 与 ARM64 原生源码，最低安装版本为 Android 14 / API 34，target API 为 37。发行附件可用 `SHA256SUMS.txt` 核对。

本次正式 APK 通过完整构建、项目离线测试、签名和 16 KB 对齐检查。以下设备结果来自开发候选。正式 APK 未单独安装验收。

- **Redmi Note 11T Pro / 澎湃 OS 2**：分项验证了添加和滚动副窗、快捷栏惯性滚动、主副交换、桌面恢复与捐赠致谢名单。`1000249` 实测滚出可见区的副窗不再抢占顶部触摸。`1000251` 同一滚动位置重开时，两扇可见副窗的起显间隔从旧测试包的约 634 毫秒降至 0 至 34 毫秒。这是分项取样，不代表所有场景的帧率。
- **Xiaomi Pad 6S Pro / 澎湃 OS 4**：`1000252` 和 `1000253` 分项验证横竖屏滚动、第五窗、向上退出、保留恢复以及换方向后保留任务。四扇可见副窗在 `1000252` 同帧开始淡入。`1000254` 实测切换方向后能打开控制中心，竖屏小窗可从左右两侧横向拉开回到主区。个别应用在重新布局时仍有短暂重绘。
- **Xiaomi 17 Pro Max / 澎湃 OS 4**：`1000256` 实测手机竖屏顶部小窗中，公众号、服务号下滑返回和公众号返回箭头均正常显示微信首页。
- **澎湃 OS 3**：既有设备结果见前版验证说明。本版新增和改进尚未完成对应真机复验。

不同 ROM 和应用组合的旋转、输入法、真实画面及退出恢复仍需单独验证。
