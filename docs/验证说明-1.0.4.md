# 1.0.4 验证说明

正式版本 `1.0.4 / 1000248`，包名 `com.jiusis.mistep`，延续 1.0.3 签名。完整编译 Java 与 ARM64 原生源码，最低安装版本为 Android 14 / API 34，target API 为 37。发行附件可用 `SHA256SUMS.txt` 核对。

本次正式 APK 通过完整构建、项目离线测试、签名和 16 KB 对齐检查。以下设备结果来自开发候选。正式 APK 未单独安装验收。

- **澎湃 OS 2 / Android 15**：Redmi Note 11T Pro 分项验证了添加和滚动副窗、退出重进、快捷栏惯性滚动、主副交换、桌面恢复与捐赠致谢名单。部分交换路径经诊断入口触发生产转场。
- **澎湃 OS 4 / Android 17**：Xiaomi 17 Pro Max 已验证部分开发候选的安装和加载。最新滚动及交换行为仍待验收。
- **澎湃 OS 3**：既有设备结果见前版验证说明。本版新增和改进尚未完成对应真机复验。

不同 ROM 和应用组合的旋转、输入法、真实画面及退出恢复仍需单独验证。
