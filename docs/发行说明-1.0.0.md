# Mi Step 1.0.0

首个正式整理发行的 Mi Step 版本：一个主区域、三个真实副任务，支持左右布局、点击主副交换和向外拖出。顶部提供常用应用、剪贴板、系统快捷操作、原生音乐卡片与歌词。

| 版本名 | `1.0.0` |
| 版本码 | `1000000`，后续同包名版本递增 |
| 包名 | `com.jiusis.mistep` |
| 架构 | ARM64 |
| 适配目标 | Android 17 / 澎湃 OS 4，Root 与 LSPosed |
| 功能基线 | 开发版 `2.9.204` |

## 功能与修复

- 保留一个主区域和三个副任务，点击交换，应用任务状态继续保留。
- 修复前台窗口贴边收起时的黑屏、贴边位置偏移及视觉与输入坐标不一致。
- 优化主副升降收尾，主区域保持焦点，副任务以点击交换和向外拖动为主要操作。
- 修复一步内部横屏的输入方向与映射，及悬浮键盘横向过早限位。
- 修复后台 Activity 干扰当前主任务旋转，导致横屏主副交换出现接缝、黑边或裁切异常的问题。
- 修复状态栏显示交接与原生隐藏竞争，补齐超时、窗口重建及退出时的恢复。
- 修复横竖屏原生状态栏退隐越出主区域：仅限制状态栏动画父层的可见画布，保留正常隐藏与显示，不增加交互冷却。

## 安装与升级

下载 `MiStep-1.0.0.apk`，使用 `SHA256SUMS.txt` 核对文件。2026-10-29 将模块包名统一为 `com.jiusis.mistep`，同步重建本版 APK 与源码附件，功能仍为原 1.0.0 基线，分身修复留到下一版。后续版本继续沿用这个包名。

已有旧包名版本的用户先退出工作区，在 LSPosed 中停用旧模块，再安装当前包、启用新模块并按 [使用说明](使用说明.md) 重新选择作用域，最后正常重启。确认正常后可卸载旧模块。改包名属于独立安装，无法直接覆盖旧包，也不会自动迁移模块配置；避免同时启用两个模块。

发行包沿用已有签名身份。后续同包名、同签名版本可以覆盖升级；自行改用其它密钥签名则不能覆盖同包名现有安装。

## 验证范围

发行包从完整 Java 与 C++ 源码构建，不复用开发 class 缓存；执行离线策略和生产方法回放、签名、16 KB 对齐、模块入口与原生库包装检查，并与 `2.9.204` 编译行为对照。

开发期在 Redmi Note 11T Pro 验证过横屏公共输入和悬浮键盘拖动；悬浮键盘限位与最新状态栏越界修复由用户在 Xiaomi 17 Pro Max 实际测试后确认修好。用户确认、开发方动态取证与离线检查分别保留记录。

本次重新打包的 **1.0.0 APK 未额外安装到手机**。不同 ROM、反向横屏、左右布局、通知拖窗、硬件副屏及所有第三方应用组合，不宣称已经统一完成实机验收。
