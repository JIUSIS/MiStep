# Mi Step 1.0.0

首个按独立项目整理的发行版本，功能基于开发版 2.9.193。显示版本为 `1.0.0`，版本码为 `1000000`，包名保留 `com.jianguo.mistep`。

## 本版内容

- 一个主区域、三个真实副任务，支持左右布局、点击交换和向外拖动。
- 保留现用的前台贴边图标黑屏修复，以及图标视觉与输入坐标映射修复。
- 保留 193 的主副升降收尾优化：去掉额外焦点复查等待，焦点跟随主区域，继续保留任务交接和最终帧输入保护。
- 顶部工具、常用应用栏、剪贴板、系统操作、原生音乐控件和歌词通道。
- 整理完整 Java / C++ 源码、构建与离线测试入口、使用与数据说明。

## 验证和限制

发行包由完整源码构建，执行签名、16 KB 对齐和模块入口包装检查。原生库与开发基准一致；Java 编译结果与 193 对照，版本标记以外的现有类字节码行为保持一致，完整编译清除了旧缓存中的残留类。

贴边问题已有用户对开发版 192 的实机修复确认；193 的焦点和收尾改动有装机、加载与日志证据。**本次 1.0.0 包未额外安装到手机**，不能把离线通过等同于全部实机体验通过。精确首击体感、副任务外拖回归及不同 ROM 的完整体验仍有待分别验收。

发行包沿用开发期间的签名身份。发布内容不包含该签名私钥、本机密码、设备日志、个人截图或 ROM 资料。
