# 澎湃 OS 3 支持

当前开发版将最低安装版本改为 Android 15 / API 35，Java 编译 SDK、Manifest、资源链接与 D8 最低 API 同步为 35，target 保持 37。小米官方 [REDMI Note 15 SE 规格](https://www.mi.com/in/product/redmi-note-15-se-5g/specs/)明确列有基于 Android 15 的 HyperOS 3。Android 15 的 ROM 私有接口和输入库尚未获得真机验证；下文 Android 16 的历史实测不能替代该项验证。正式 1.0.2 发行包仍保持原 API 36 下限。

1.0.2 正式版已包含 OS 3 适配、真实任务翻转和输入法修复。下文内部 42、43、50 是各阶段历史验证记录，其待验项不代表后续从未验证；截至发布的结果以[1.0.2 验证说明](验证说明-1.0.2.md)为准。旧 v1.0.1 发行包不包含 OS 3 支持。

## 改动范围

- 兼容 OS 3 的 TaskView 原生接口、R8 内联方法、开关动画及已保存任务重新接入。复用当前 Shell organizer，只处理 MiStep 持有的任务。
- 按实际 framework 实现兼容主区缩放事务、IME 和壁纸接口；原 OS 4 方法存在时优先原调用，原调用失败不会被兼容分支吞掉。
- 为本次系统增加输入库精确 profile。原始触摸补偿仍要求三库 SHA256、函数前导指令及已核结构布局匹配；未知库不会盲套本次地址。系统界面可显示不代表未知系统的触摸已经通过。
- 兼容控制中心插件和原生图标、亮度事件及 SettingsLib 逆亮度方法；音乐页使用原生播放器及独立 SeekBar 模型，适配 ConstraintSet 的参数顺序。
- 正式 1.0.2 当时使用 API 36 SDK，Manifest 与 D8 最低 API 为 36，target API 为 37；当前开发版下限见本文开头。WindowInspector 通过能力检测使用，缺少扩展监听时使用原窗口增删事件。

## 验证与边界

内部 43 完整 Java/C++ 构建、签名与全部离线测试通过；针对 OS 3 兼容层的 33 项、亮度原生调用选择的 8 项通过。已在上述 11T 安装并正常重启，确认本次 system_server、SystemUI 和精确 native profile 加载。

同一适配链路在内部 42 已实际验证：主区缩放、真实副任务收纳、主副交换、退出及同一任务再次进入。独立无权限触点探针的两个主区触点误差小于 1 px，验证后已卸载。43 只追加亮度逆变换和原生音乐布局加载兼容，没有改动这条任务与输入链路。

43 原生音乐空状态卡片已显示，之前的“原生音乐控件未就绪”已消失。没有活动播放会话，播放按钮、进度拖动及歌词仍待实测。亮度读值出现小幅变化，但共同操作期间无法明确归因；几次反向翻页与管理器点击注入也未获得明确结果，因此亮度滑条、反向翻页均列待验，不把没有异常日志等同于触摸验收。顶部横屏窗口、更多应用及其他机型仍未做系统验收。

完整证据保存在项目研究目录 `research/onestep/os3-support-20261101/`，含取得的系统二进制摘要、定向反编译定位、原始日志、截图、操作时间和源码基线。本仓库不打包系统 APK 或用户设备数据。

## 内部 50：真实任务翻转与输入法

- TOP 翻面、主区收进 TOP 及翻回主区使用原应用 TaskView／Surface／native leash；移除这些路径上的截图过渡。取消或失败恢复真实任务及原变换，不以静态应用图像补画。翻转前调整真实控制面板的绘制顺序，避免 SurfaceView 透明洞把另一面清成黑带。
- OS 3 的窗口扫描只排除 MiStep 有效租约内的被动纵向副任务，必要时通过原生 `setFocusedApp` 同步 Activity 焦点。当前有真实焦点、精确租约的 TOP 编辑窗口保留原生 IME layering 资格并控制自己的输入法，不强制全局显示、不新增普通应用作用域。
- 内部 50 完整 Java/native 构建与全部离线测试通过；11T 新 boot 上主区、TOP 的普通触摸均实际弹出键盘，系统设置真实搜索框也通过。内部 49 另验证中文提交、取消保留及有副任务时的主区输入。50 单次真实翻回录像显示内容持续更新、同一 task 存活返回，之前的黑带消失。
- 上述真机结果限本机 OS 3 和记录中的应用场景；OS 4 共用修正尚未实机验收，更多应用兼容性仍待体验。主区状态栏偶现隐藏只做只读分析，本次未改变状态栏策略，也未确认根因。

本批详细证据为 `research/onestep/top-live-ime-20261102/`。临时探针卸载，临时 LSPosed 开发者模式已通过管理器界面关闭；版本 50 已保数据安装，未发布正式版。

## 使用刷机包进行后续适配

刷机包可以用于提取 framework、SystemUI、控制中心插件和三份输入库，完成大部分接口差异分析与输入 profile 的静态校验。本次使用手机只读取得的同类原始文件完成这部分工作。仅刷机包不能证明注入框架已加载、实际触点命中、交换动画与异常退出恢复；新增 ROM 仍需有界真机验证。
