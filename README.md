# Mi Step

**一个主区域，三个副任务，把手机上的多任务放在一起。**

Mi Step 是面向小米澎湃 OS 的多任务工作区。主区域保留完整的系统操作，旁边放置三个真实应用任务；点一下副任务即可与主区域交换，也可以向外拖出。聊天、查资料、看内容，不必反复在最近任务里来回切换。

当前发行版：**1.0.0**。项目正在私库内维护。

## 可以做什么

- **主副交换**：副任务点击后升为主区域，原来的主任务进入副任务区。
- **真实应用任务**：副任务由系统 TaskView 承载，保留任务状态，主副区域互不遮挡。
- **左右布局**：从左上角或右上角向屏幕内侧滑动，打开对应方向的工作区。
- **副任务向外拖动**：保留原生任务交接，副任务区以点击交换和向外拖动为主要操作。
- **顶部工具**：常用应用入口、剪贴板、系统快捷操作，以及原生音乐控件与滚动歌词。
- **系统协调**：处理主区域缩放、触摸坐标、输入法、旋转和原生小窗共存；主区域保持输入焦点。

## 适用环境

本项目是 **LSPosed 系统模块**，需要已有 Root 与兼容的 LSPosed 环境。当前研发目标为 **Android 17 / 澎湃 OS 4、ARM64**，使用小米系统内部接口，不能按普通 Android 应用理解兼容性。

开发期间使用过 Xiaomi 17 Pro Max 和 Redmi Note 11T Pro。不同机型、ROM 版本和系统更新可能改变内部接口，需要分别验证。Manifest 的最低安装版本不代表功能兼容范围。

## 下载与开始使用

从仓库的 **Releases → v1.0.0** 下载 `MiStep-1.0.0.apk`，同页提供 SHA-256 校验文件。

安装、启用作用域、入口与退出方法见 [使用说明](docs/使用说明.md)。源码构建见 [构建说明](docs/构建说明.md)，本次版本的变更与验证边界见 [1.0.0 发行说明](docs/发行说明-1.0.0.md)。

## 源码结构

| 路径 | 内容 |
| --- | --- |
| `module/src/main/java/` | 宿主工作区、系统桥、主副任务与输入策略 |
| `module/src/main/cpp/` | 原生输入映射与保护 |
| `module/src/main/res/`、`assets/` | 产品图标和模块入口 |
| `tests/` | 独立策略测试、原生自测源码 |
| `tools/` | 生产方法回放、模拟系统接口和 APK 包装检查 |
| `build.ps1`、`test.ps1` | Windows 下完整源码构建与离线测试入口 |
| `docs/` | 产品、使用、构建和发布说明 |
