# Mi Step

**一个主区域，三个副任务，让手机多任务真正并排使用。**

Mi Step 是面向小米澎湃 OS 的多任务工作区。它将当前系统界面缩放到主区域，在旁边保留三个真实应用任务。点击副任务即可与主区域交换，应用原有的页面和任务状态继续保留。

看内容时切回聊天、查资料时对照笔记、在几个应用间处理同一件事，都可以在一个工作区内完成。副任务区负责快速切换和向外拖出；输入和页面操作集中在主区域。

## 功能

| 功能 | 使用体验 |
| --- | --- |
| 主副交换 | 点击副任务，原主任务进入副区，选中的任务成为主区域 |
| 三个真实副任务 | 使用系统任务承载应用，保留页面状态，与主区域并排显示 |
| 左右布局 | 从左右上角进入对应布局，按使用习惯安排主副区域 |
| 向外拖出 | 将副任务拖出工作区，与系统原生小窗交接 |
| 横屏应用和悬浮键盘 | 在一步内部使用横屏页面，协调方向、触摸映射和键盘可移动范围 |
| 顶部工具区 | 常用应用入口、剪贴板、系统快捷操作、原生音乐卡片和歌词 |

主区域保持输入焦点。主副交换完成后恢复操作；任务交接期间保留必要的输入保护。

## 运行要求

- 已有可用的 **Root 和 LSPosed**，并能为模块启用推荐作用域。
- 当前适配目标：**Android 17 / 澎湃 OS 4，ARM64**。
- 使用小米系统内部接口，系统更新或不同 ROM 可能需要重新适配。

开发和验证使用过 **Xiaomi 17 Pro Max** 与 **Redmi Note 11T Pro**。机型名称、Manifest 的最低安装版本，都不能单独证明某个 ROM 完整兼容。具体修复和验证范围见 [发行说明](docs/发行说明-1.0.0.md)。

## 开始使用

1. 从 [v1.0.0 Release](https://github.com/JIUSIS/MiStep/releases/tag/v1.0.0) 下载 `MiStep-1.0.0.apk`，按同页 `SHA256SUMS.txt` 核对文件。
2. 安装并在 LSPosed 中启用 Mi Step，选择模块推荐作用域，然后正常重启。
3. 在竖屏界面，从左上角向右或右上角向左滑动，打开工作区。
4. 点击副任务格的 **＋** 添加应用，点击副任务与主区域交换；通过顶部退出按钮恢复普通界面。

模块没有普通启动 Activity，安装后通过系统手势进入。推荐作用域、覆盖升级及停用恢复方法见 [使用说明](docs/使用说明.md)。

## 源码与构建

| 路径 | 内容 |
| --- | --- |
| `module/src/main/java/` | 工作区、任务交换、系统桥、焦点与输入策略 |
| `module/src/main/cpp/` | 原生输入映射与边界保护 |
| `module/src/main/res/`、`module/src/main/assets/` | 产品图标及模块入口 |
| `tests/`、`tools/` | 策略测试、生产方法回放和 APK 检查 |
| `build.ps1`、`test.ps1` | Windows 下完整源码构建与测试入口 |
| `docs/` | 使用、构建、发行和数据说明 |

构建需要自行准备 Android SDK、NDK、JDK 和 Python。详细版本及命令见 [构建说明](docs/构建说明.md)，编译不依赖设备采集材料或开发期间的 class 缓存。
